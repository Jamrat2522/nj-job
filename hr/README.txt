7) โหมด "รวมเงินเดือน" (เมนู เงินเดือนและสวัสดิการ)
------------------------------------------------------------
- สิทธิ์: SUPER_ADMIN / ADMIN / ACCOUNT
- อัปโหลด 2 ไฟล์ (ไฟล์สรุปเวลา + ไฟล์ลา) แล้วกด EXPORT EXCEL
- ได้ไฟล์ MASTER_เงินเดือน_รวม_ปรับรูปแบบ.xlsx จาก MASTER ที่ฝังใน
  ระบบ (master-salary.js) คงข้อมูล/สูตร/รูปแบบคอลัมน์ A-P เดิม 100%
- เติม 11 หัวข้อ Q-AA ตามลำดับ: ขาดงานเข้า, ขาดงานออก,
  ไม่จำเป็นต้องลงชื่อเข้างาน, สายกี่นาที, ทำงานล่วงเวลา(ชม.),
  ลงชื่อย้อนหลัง, ลากี่วัน, ลากิจ, ลาพักร้อน, ลาป่วย, ลาอื่น
  + แถวรวม 116 สูตร =SUM(?2:?111)
- ระบบอ่านหัวข้อจริงจาก Master ก่อนเขียน (ลำดับไม่ตรง = หยุดทันที)
- นับเฉพาะสถานะ "อนุมัติแล้ว" ของเดือนเป้าหมาย (อ่านเดือนจากหัว
  คอลัมน์ไฟล์สรุปเวลา) / ลาข้ามเดือนคิดเฉพาะส่วนที่อยู่ในเดือน /
  กันรายการซ้ำด้วยหมายเลขการอนุมัติ / มาสายคิดจากเวลาเริ่ม 08:30
- จับคู่รหัส 2 ชั้น: ตรงตัวก่อนเสมอ รหัสมีอักขระท้าย (เช่น 0410*)
  จับคู่ได้เมื่อไม่มีรหัสตรงตัวในไฟล์เดียวกัน + ชื่อตรงกับ Master
  รหัสที่ไม่มีใน Master จะข้ามและแจ้ง ไม่เพิ่มรายชื่อใหม่
- Number Format: ลงชื่อย้อนหลัง = "0", วันลาค่าเต็ม = "0" /
  ค่าครึ่งวัน = "0.#" (เก็บค่าจริง 0.5 ไว้ ไม่ปัดค่า)
- Sheet 3 "รายละเอียดการลาและการมาทำงาน": 1 คน 1 แถว 21 คอลัมน์
  (ลำดับ, ชื่อ, ขาดงานเข้า/ออก+รายละเอียด, สาย(ครั้ง)+รายละเอียด,
  OT ชม.+รายละเอียด, ลงชื่อย้อนหลัง+รายละเอียด, ลาป่วย/ลากิจ/
  ลาพักร้อน/ลาอื่น จำนวนวัน+รายละเอียด, รวมวันลา)
  วันที่รูปแบบ DD/MM/YYYY ต่อเนื่องรวมช่วงอัตโนมัติ เช่น
  02/07/2026 - 04/07/2026, 08/07/2026
  ไม่มีข้อมูลแสดง "-" หัวตารางแบ่งสี 3 กลุ่ม (ขาดงาน/การทำงาน/การลา)
  Freeze หัวตาราง + Filter + Auto Fit + ตัวเลขไม่มีจุดทศนิยม
- Sheet 4 "รายละเอียดและคำนวณ OT": ข้อมูล OT ทั้งหมดอยู่ชีตนี้ที่เดียว
  (ตัดออกจากชีตรวมลา/รายละเอียดแล้ว — ชีตรวมลาแสดง "สาย" แทน)
  1 รายการ OT = 1 แถว 16 คอลัมน์: เงินเดือน (Master คอลัมน์ D),
  วันที่ DD/MM/YYYY, ประเภทวัน (จากข้อมูลระบบบริษัท ไม่ใช่ดูเสาร์-
  อาทิตย์), เวลา HH:MM, ชั่วโมงแยก 1.5/1/3 เท่า, ค่าแรงต่อวัน (÷30),
  ต่อชั่วโมง (÷30÷8), เงินแต่ละอัตรา + เงิน OT รวม
  กฎ: วันธรรมดา 1.5 เท่าทั้งช่วง / วันหยุด 08:30-17:30 = 1 เท่า,
  17:30-18:00 ไม่คิด, หลัง 18:00 = 3 เท่า
  ยอดเงิน OT รวมต่อคนส่งกลับชีต 1 คอลัมน์ "ทำงานล่วงเวลา" (หน่วยบาท
  รูปแบบ #,##0.00) — ชั่วโมงรายวันดูจากชีต 4
  สีหัว: ชม.1.5 ฟ้า / ชม.1 ส้มอ่อน / ชม.3 แดงอ่อน / เงินรวม เขียว
- Sheet 2 "รวมลา": สรุปต่อคน 1 แถว (ลำดับ/รหัส/ชื่อ + ลากี่วัน,
  ลากิจ, ลาพักร้อน, ลาป่วย, ลาอื่น, ขาดงานเข้า, ขาดงานออก,
  ทำงานล่วงเวลา, ลงชื่อย้อนหลัง) บรรทัดแรกแสดงจำนวน บรรทัดถัดไป
  แสดงวันที่ (พ.ศ.) OT มีชั่วโมงต่อรายการ ไม่มีข้อมูลแสดง "-"
  เปิด Wrap Text / Freeze หัวตาราง / Filter / ปรับความกว้างอัตโนมัติ
  เรียงรหัสน้อย → มาก
- ตรวจสอบอัตโนมัติก่อนสร้างไฟล์ + เปิดไฟล์ตรวจซ้ำก่อนดาวน์โหลด
- โหมดนี้ต้องมีอินเทอร์เน็ตครั้งแรกเพื่อโหลด SheetJS/JSZip จาก CDN

9) พื้นที่ลงเวลา (Geofence) — เมนู จัดการระบบ (เฉพาะ SUPER_ADMIN)
------------------------------------------------------------
- ตั้งชื่อสถานที่ / ปักหมุดบนแผนที่ (Leaflet + OpenStreetMap ต้องมี
  อินเทอร์เน็ต — ออฟไลน์ยังกรอก Latitude/Longitude เองได้ครบ) /
  ใช้ตำแหน่งปัจจุบัน / รัศมี (ปุ่มลัด 50-500 ม. หรือกรอกเอง วงกลม
  ขยาย-หดทันที) / ความแม่นยำ GPS สูงสุดที่ยอมรับ
- โหมด Prototype (จำลอง GPS ด้วย checkbox → สร้างพิกัดทดสอบแล้ว
  คำนวณระยะจริง) / Production (บังคับ GPS จริง + Geofence +
  Accuracy ทุกครั้งที่ลงเวลา ทั้งหน้าลงเวลาและปุ่มลัดหน้าหลัก)
- ทดสอบพื้นที่: คลิกแผนที่/กรอกพิกัด/ตำแหน่งปัจจุบัน/สถานการณ์จำลอง
  (ภายใน-ขอบ-นอกรัศมี ซึ่งมีหน้าที่สร้างพิกัดเท่านั้น) → คำนวณ
  Haversine จริงทุกครั้ง: ระยะ ≤ รัศมี = ผ่าน (200/200 ผ่าน,
  201/200 ไม่ผ่าน) แสดงพิกัด/ระยะ/เหตุผลครบ + ปุ่มล้างข้อมูลทดลอง
- สิทธิ์: ตรวจ role === 'SUPER_ADMIN' (มาตรฐานเดิมของระบบ) ซ้ำทุก
  ชั้น — เมนู, route, เปิดหน้า, ทุกปุ่ม/ทุกฟังก์ชันแก้ไข ไม่ใช่แค่ซ่อน
  ปุ่ม; role อื่นเปิด URL ตรงจะถูกพากลับพร้อมข้อความ; ฟังก์ชันอยู่ใน
  closure เรียกจาก Console ไม่ได้
- บันทึกลงตารางตั้งค่าเดิม (db.settings.geofence) พร้อม updated_at/
  updated_by/role + Audit Log เก็บค่าเดิม→ค่าใหม่ + อุปกรณ์
- หน้าลงเวลาอ่านค่าล่าสุดทุกครั้ง (ไม่มี hardcode/ค่าค้าง) — ถ้าโหมด
  Production แต่ยังไม่ตั้งค่า จะบล็อกพร้อมข้อความให้ติดต่อ Super Admin
- Production (Supabase) ให้ใช้ RLS ตามนี้ (ตาราง app_settings แถว
  geofence, ตาราง users มีคอลัมน์ role):
    alter table app_settings enable row level security;
    create policy geo_read on app_settings for select using (true);
    create policy geo_write on app_settings
      for all using (
        exists (select 1 from users u
                where u.id = auth.uid() and u.role = 'SUPER_ADMIN'))
      with check (
        exists (select 1 from users u
                where u.id = auth.uid() and u.role = 'SUPER_ADMIN'));
  หมายเหตุ: Prototype นี้เก็บใน localStorage แทน Supabase ตาม
  สถาปัตยกรรมเดิมของระบบ — โครงข้อมูล/สิทธิ์ออกแบบให้ย้ายได้ตรง 1:1

10) ตั้งค่ากะทำงาน — เมนู จัดการระบบ (SUPER_ADMIN / ADMIN / HR)
------------------------------------------------------------
- ตาราง: db.shifts (id, name, start, end, breakMins, overnight,
  active, updatedAt, updatedBy) + พนักงานผูกด้วย employee.shiftId
  โดยระบบ sync ฟิลด์ employee.shift (string เดิม) ให้ตรงกะเสมอ
  → โค้ด/รายงานเดิมที่อ่านค่าเดิมทำงานต่อได้ ไม่มี hardcode
- Migration อัตโนมัติครั้งแรก (idempotent): สร้างกะจากค่ากะเดิมของ
  พนักงานทุกแบบ (08:30-17:30 = "กะปกติ") ผูกพนักงานครบทุกคน
  ตรวจจำนวนก่อน/หลัง ข้อมูลเดิมไม่หาย
- หน้าจัดการ: ค้นหา/กรองสถานะ/กรองประเภท/จำนวน, เพิ่ม/แก้ไข
  (ชื่อไม่ซ้ำ ตรวจเวลา กะปกติ end>start / กะข้ามวัน end<start),
  เปิด-ปิดใช้งาน (confirm + เตือนจำนวนคน), ลบ (บล็อกถ้ามีพนักงาน
  พร้อมรายชื่อ), ดูรายชื่อพนักงานในกะ
- เลือกพนักงานเข้ากะ: ช่องค้นหา sticky (รหัส/ชื่อ/นามสกุล/ชื่อเล่น
  บางส่วน), เลือกทั้งหมดที่แสดง/ล้าง, นับจำนวน, แสดงกะปัจจุบัน;
  ย้ายข้ามกะมีหน้าต่างยืนยัน; พนักงาน 1 คนอยู่ได้ 1 กะเสมอ
  (คนที่ถูกเอาออกย้ายไปกะแรกที่ยังใช้งานอัตโนมัติ)
- การคำนวณเวลาอ้างอิงกะพนักงาน: สาย = เข้าหลัง start+อนุโลม,
  กะข้ามวันสแกนเข้าหลังเที่ยงคืนไม่นับสายผิดวัน, ออกงานหลังเที่ยงคืน
  ปิด record ของวันที่เข้างาน (ไม่นับเป็นวันใหม่)
- ฟอร์มพนักงาน: กะทำงานเป็น Dropdown (เฉพาะกะที่ใช้งาน) แสดง
  ชื่อกะ · เวลา (+วันถัดไป)
- หน้าขอ OT: แสดงกะ+เวลาเลิกงาน, เวลาเริ่ม OT ตั้งต้น = เวลาเลิกกะ,
  เตือนเมื่อ OT ซ้อนเวลาทำงานปกติ (ไม่บล็อก), OT ข้ามวันคำนวณถูก
- หน้าอนุมัติ 3 แท็บ จัดระเบียบใหม่ (logic เดิมทั้งหมด):
  ลา = badge ประเภท+วันที่+จำนวนวัน+คงเหลือ / OT = badge คำขอ OT+
  วันที่+กะ+เวลา+ชม. / แก้ไขเวลา = badge+วันที่+กะ+เดิม(ขีดฆ่า)→ใหม่(เด่น)
  ปุ่มอนุมัติ/ไม่อนุมัติ/ขอข้อมูลเพิ่ม สูง 44px กดง่ายบนมือถือ

11) ขอ OT — รายการงาน OT (หลายรายการ + ไฟล์แนบ)
------------------------------------------------------------
- ตาราง: ลำดับ(อัตโนมัติ) | JOB | รายละเอียด | ประเภทงาน (ตรวจปล่อย/
  คีย์ใบขน/คีย์+ตรวจปล่อย) | วันที่ | เวลาเริ่มต้น | สิ้นสุด | แนบไฟล์
- เพิ่ม/ลบรายการได้, แนบหลายไฟล์ต่อรายการ (PDF/Excel/Word/รูป
  ≤2MB/ไฟล์) ไฟล์ผูกกับรายการนั้น มีปุ่ม ดู/ดาวน์โหลด/ลบ
- ตรวจช่องบังคับ + เวลาสิ้นสุด>เริ่มต้น ก่อนส่ง (กรอบแดงตรงช่อง)
- รายละเอียด/หน้าอนุมัติแสดงรายการงาน+ไฟล์ครบ ดาวน์โหลดได้
- คอมพิวเตอร์แสดงเป็นตาราง มือถือแสดงเป็นการ์ดแนวตั้ง
