RUN-147 — ข้อกำหนดที่ยืนยันกับผู้ใช้
================================================================
อนุมัติคำขอของตนเองได้ เฉพาะเมื่อครบทุกข้อ
  1. เป็น current approver จริง
  2. njhr_leave_can_act(...).allowed = true
  3. ขั้นปัจจุบันมีผู้อนุมัติที่ใช้ได้เพียง 1 คน
  4. และคนนั้นคือผู้ยื่นเอง
ถ้ามี approver คนอื่นในขั้นเดียวกัน -> ห้ามผู้ยื่นอนุมัติตัวเอง

ล็อกเพิ่ม 3 ข้อ
  L1 njhr_leave_self_sole_approver() เป็นเพียงข้อยกเว้นของ self-request guard
     ห้ามใช้แทน permission check หลัก -> can_act(...).allowed ต้องเป็น true เสมอ
  L2 การนับ "ผู้อนุมัติที่ใช้ได้ = 1 คน" ต้องนับเฉพาะคนที่ eligible จริงของขั้นปัจจุบัน
     ไม่ใช่นับ row ที่ตั้งไว้ใน workflow เฉย ๆ
  L3 เขียน audit_log action = SELF_APPROVAL_SOLE_APPROVER เมื่อใช้ข้อยกเว้นนี้

Root Cause (วัดด้วยข้อมูล Production จริง)
  ใบ 260918-0041 ของ นางสาวกนกวรรณ มหันโต (0155) แผนก ACCOUNT
  workflow 557caeea ขั้นที่ 1 "หัวหน้างาน" mode ALL · ผู้อนุมัติของขั้น = ตัวเธอเอง คนเดียว
  njhr_leave_can_act = allowed TRUE แต่ถูกบล็อกด้วยเงื่อนไข self-request 3 จุด
  (feed -> act · feed -> WHERE ท้าย · decide -> hard guard)
  ผลคือใบนี้ค้างถาวร ไม่มีใครในระบบกดได้เลย
  (หลัง RUN-146 ถอด bypass ของ SUPER_ADMIN ทางออกฉุกเฉินเดิมก็หายไปด้วย)

สิ่งที่แก้
  ใหม่  njhr_leave_self_sole_approver(uuid)   ข้อยกเว้นของ self-request guard
