HR V2 — ตรวจการโหลดไฟล์บนเซิร์ฟเวอร์จริง

หน้านี้เป็น HTML ธรรมดา ไม่ใช้ ES Module จึงเปิดได้แม้ระบบหลักพัง · ไม่แตะระบบ V1 · ไม่เขียนข้อมูลใด ๆ

⛔ กำลังเปิดจากไฟล์ในเครื่อง (file://) — ผลตรวจใช้ไม่ได้

HR V2 เป็น ES Module เบราว์เซอร์ ห้ามโหลด module และ fetch ผ่าน file:// ทุกไฟล์จึงขึ้น "Failed to fetch" ทั้งหมด — ไม่ได้แปลว่าไฟล์หายหรือเซิร์ฟเวอร์ผิด

ต้องเปิดผ่าน HTTP เท่านั้น เลือกอย่างใดอย่างหนึ่ง:
① อัปโหลดขึ้นโฮสต์แล้วเปิด https://<โดเมน>/hr-v2/diag.html
② ทดสอบในเครื่อง: เปิด Command Prompt ที่โฟลเดอร์ hr-v2 แล้วพิมพ์ python -m http.server 8080 จากนั้นเปิด http://localhost:8080/diag.html
