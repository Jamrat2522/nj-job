RUN-164  ประกันสังคม "ลูกจ้าง 5%" — ปัดขึ้น + เพดานฐาน 17,500 + CAP 875
================================================================
กติกา  employee_base = MIN(ฐานค่าจ้างจริง, 17500)
       ลูกจ้าง       = MIN(CEIL(employee_base x 5%), 875)
       ปัดขึ้นเป็นจำนวนเต็มทุกกรณี · คำนวณจากฐานจริงก่อนแล้วค่อย CAP

Root Cause — มี 2 จุดคำนวณที่แยกกันและผิดทั้งคู่
  1) DB  njhr_sso_base()   -> หน้า "ประกันสังคม" / njhr_sso_snapshot
       round(v_base * rate_employee / 100, 0) + ฐานถูกตัดที่ cfg.base_max = 15,000
       -> ปัดครึ่งไม่ใช่ปัดขึ้น และลูกจ้างได้เพดาน 750 เสมอ
  2) Frontend compat/approvals-reports.js (viewPayroll -> ปุ่มคำนวณเงินเดือน)
       Math.min(Math.round(x.baseSalary*.05), 750)
       -> ปัดครึ่ง · เพดานยอด 750 · ไม่มีเพดานฐาน
     payroll.social_security มาจาก Frontend ล้วน (period_save/recalc_row ไม่คิด ปกส. ใหม่)
     จึงต้องแก้ทั้งสองจุดถึงจะตรงกันทั้ง Payroll / สลิป / PDF / Excel
