NJHR V2 — RUN-131 · Approval UI: ซ่อน Future Step / ขั้นที่ผ่านแล้วเป็น History
Build: njhr-v2-d69e38a9  (ก่อนหน้า: njhr-v2-45185d41)
สถานะ: FRONTEND_ONLY · NO_SQL · DEPLOY_PENDING · REAL_DEVICE_VERIFICATION = NOT_RUN

รอบนี้ไม่มี SQL — RUN-128 / RUN-129 / RUN-130 ติดตั้งบน Production ไปแล้ว
ห้ามรันซ้ำ (เป็น Migration แบบ text-rewrite ของ Function เดิม รันซ้ำจะ raise exception)

Root Cause
  RC-1  apprWhoState() ไม่มีสถานะ "ขั้นที่ผ่านแล้ว"
        หลัง RUN-128 Backend (njhr_appr_steps_snap) ตัด Future Step ทิ้งก่อนส่งมาแล้ว
        steps ที่ Frontend ได้รับจึงมีได้แค่ "ขั้นปัจจุบัน" กับ "ขั้นที่ผ่านแล้ว"
        แต่โค้ดยังตกไปที่ป้าย "ยังไม่ถึงขั้น" ทุกกรณีที่ไม่ใช่ขั้นปัจจุบัน
        หลักฐาน Production: 260902-0007 (cur=3 · steps 3 ขั้น) และ 260902-0002 (cur=2 · steps 2 ขั้น)
        แต่ละใบมีผู้อนุมัติในขั้นที่ผ่านแล้ว 1 คนที่ไม่ได้กด → ถูกแปะว่า "ยังไม่ถึงขั้น"
  RC-2  apprStepsHTML() คำนวณ wait เองโดยไม่เช็ค status
          var wait = cur && s.step_no === cur;        (ขาด && status === "PENDING")
        Production มี CANCELLED 6 แถวที่ current_step ยังค้าง 1–2
        (APPROVED / REJECTED เป็น NULL หมดแล้ว) → ใบที่จบแล้วกลับไปโชว์ "รออนุมัติ"
  RC-3  apprStepsHTML() ไม่รู้จัก step_mode = ANY
        หน้าอนุมัติกับหน้าพนักงานจึงเขียนข้อความคนละอย่างกับใบเดียวกัน
  RC-4  apStepsHTML() (ฝั่งพนักงาน) ขั้น ALL ที่ผ่านแล้ว / ใบที่ปิดแล้ว
        ตกไปที่ "รอดำเนินการ" ซึ่งยังสื่อว่าค้างอยู่

สิ่งที่แก้ — 2 ไฟล์ Runtime

                          - ลบป้าย "ยังไม่ถึงขั้น" ออกจากโค้ดที่ทำงานจริง
