# ฟอนต์สำหรับ Final PDF — TH Sarabun New

วางไฟล์ฟอนต์จริงในโฟลเดอร์นี้ก่อน Deploy
**ระบบจะไม่สร้าง PDF ถ้าไม่มีฟอนต์ และจะไม่สลับไปใช้ฟอนต์อื่นเองเด็ดขาด**

ต้องมีอย่างน้อย 2 ไฟล์:

* น้ำหนักปกติ (Regular)
* น้ำหนักหนา (Bold)

## ไม่ต้องตั้งชื่อไฟล์ตายตัว

ตัวโหลด (`index.ts` → `loadFonts()`) **สแกนโฟลเดอร์นี้จริงตอน runtime**
แล้วเลือกไฟล์เอง ไม่ได้ hardcode ชื่อไว้ จึงรองรับชื่อที่พบได้ทั่วไป เช่น

```
THSarabunNew.ttf              THSarabunNew Bold.ttf
THSarabunNew-Regular.ttf      THSarabunNew-Bold.ttf
TH Sarabun New Regular.ttf    TH Sarabun New Bold.ttf
THSarabun.ttf                 THSarabun-Bold.ttf
```

กติกาการเลือก
* ต้องเป็นนามสกุล `.ttf` (TrueType) เท่านั้น
* **Bold** = ไฟล์ที่ชื่อมีคำว่า `bold` และไม่มี `italic` / `oblique`
* **Regular** = ไฟล์ที่ไม่ใช่ bold และไม่ใช่ italic
* ถ้าหาไม่ครบทั้งคู่ → หยุดทำงาน และแจ้งรายชื่อไฟล์ที่พบจริงในโฟลเดอร์

## ทำไมต้องเป็น .ttf เท่านั้น

ทดสอบแล้วพบว่าฟอนต์แบบ **OTF/CFF** ใช้กับ `pdf-lib` ไม่ได้
poppler เตือน `Mismatch between font type and embedded font file`
และตัวอักษรไทยบางตัว (เช่น สระ า) หายไปเมื่อถอดข้อความกลับ

## ทำไมต้องเป็นไฟล์ในโปรเจกต์

Edge Function ดึงฟอนต์จาก CDN ตอน runtime ไม่ได้
และ PDF ต้อง **embed** ฟอนต์ลงในไฟล์ ไม่งั้นเปิดบน Windows / macOS / Android / iPhone
ที่ไม่มีฟอนต์ตัวนี้ ภาษาไทยจะกลายเป็นสี่เหลี่ยม

## ห้าม

* ห้ามใช้ `Prompt` สำหรับ Final PDF (ยกเลิกแล้ว)
* ห้ามใช้ `Loma` หรือฟอนต์อื่นในเครื่องแทน
* ห้าม fallback เป็น Helvetica สำหรับข้อความไทย
* ห้ามดาวน์โหลดฟอนต์จากอินเทอร์เน็ตเอง

## ลิขสิทธิ์

TH Sarabun New เป็นฟอนต์ราชการไทยจากกรมทรัพย์สินทางปัญญา (13 ฟอนต์แห่งชาติ)
อนุญาตให้ใช้และเผยแพร่ได้ รวมถึงการฝังลงในเอกสาร
ผู้ดูแลโปรเจกต์เป็นผู้จัดหาไฟล์ฟอนต์เอง
